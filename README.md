# [CopilotKit](https://www.copilotkit.ai/) Generative UI Example

## Setup

1. Install dependencies with `npm install`.
2. Create an OpenAI API key in the [OpenAI platform](https://platform.openai.com/api-keys).
3. Add `OPENAI_API_KEY=your_api_key` to `.env.local`.
4. Start the app with `npm run dev`. Restart the server after changing the key.

The app uses `gpt-4o-mini`. OpenAI API usage may incur charges; see the
[pricing page](https://platform.openai.com/docs/pricing).
